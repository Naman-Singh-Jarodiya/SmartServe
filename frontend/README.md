# SmartServe UI Refresh

This package contains the refreshed React `src` folder for SmartServe.
The redesign is CSS-first and preserves the existing API/business logic.

Key UI changes:
- Premium responsive shell with SmartServe header/navigation
- Redesigned auth, dashboard, service, booking, address, technician and admin pages
- Glassy cards, badges, responsive grids, polished buttons and forms
- No backend/API contract changes
